Guide / Data quality

Find data-quality issues before preparing a dataset.

Elessar profiles missing values, duplicate rows, placeholders, inconsistent labels and semantic types. Start with focused checks, then generate a complete report when you need the wider statistical context.

Inspect a small, deliberately messy DataFrame

import pandas as pd
import elessar

df = pd.DataFrame({
    "customer_id": ["C001", "C002", "C002", "C004"],
    "amount": [12.5, None, None, 40.0],
    "channel": ["Web", "store", "store", "web "],
})

types = elessar.see_types(df)
quality = elessar.see_quality(df)

print(types)
print(quality["alerts"])

The example includes a repeated row, missing amounts and labels that differ in case or whitespace. Exact semantic decisions and alerts depend on the values, column names and configured thresholds; inspect the returned results rather than assuming a particular classification from the example.

Read semantic types rather than dtypes alone

A pandas object column can contain dates, identifiers, numbers stored as text, emails or free text. Elessar records a semantic type together with confidence, certainty and a decision path. This gives you evidence to check before choosing encodings or statistical tests.

config = elessar.StoneConfig(
    column_types={"customer_id": "id", "channel": "categorical"}
)
types = elessar.see_types(df, config=config)

Use overrides when domain knowledge determines a column's role. A product code is not a measured quantity just because it is stored as an integer.

Generate the full quality and preparation report

report = elessar.see(
    df,
    out_dir="quality_report",
    open_report=False,
)
print(report.alerts)
print(report.preparation)

With plots enabled, open quality_report/report.html for the findings, charts and suggested preparation code. The preparation plan is advice to review; calling see() is not a request to execute the suggested cleaning code on your source data.

Interpret diagnostics in context

  • A rare value or an outlier can be valid. Check its meaning before removing it.
  • Missingness can carry information; inspect it alongside your target and data-collection process.
  • Strong associations and leakage flags are reasons to investigate. They do not establish causality or prove leakage.
  • For sampled large datasets, check which figures cover every row and which use a sample.
