Getting started / Elessar {{VERSION}}

From a DataFrame to your first EDA report.

Install elessar from PyPI and call elessar.see(). Use Python 3.10 or newer.

InstallFirst reportFiles and CLIExports

Install from PyPI

python -m pip install elessar

The package installs pandas, NumPy, SciPy, Matplotlib, scikit-learn, Dask, PyArrow and Excel readers as dependencies. Check the installed version with python -m elessar --version.

Run a complete example

This example creates its own small, illustrative dataset. It needs no download or external account. The target column is supplied explicitly.

import pandas as pd
import elessar

df = pd.DataFrame({
    "units": [2, 4, 3, 7, 5, 9, 6, 8, 1, 4, 3, 6],
    "channel": ["web", "store", "web", "store"] * 3,
    "revenue": [20, 45, 31, 76, 53, 91, 64, 85, 12, 43, 32, 65],
})

report = elessar.see(
    df,
    target="revenue",
    out_dir="elessar_example",
    open_report=False,
)

print(report.summary)
print(report.alerts)
print(report.out_dir)

With the default plots=True, Elessar writes charts, report.html and report.md to the output directory. Open elessar_example/report.html in a browser. The tiny dataset demonstrates the API; it is not a statistical validation benchmark.

For unsupervised exploration, omit target. target="ask" requests an interactive picker. In scripts and CI, use an explicit target or no target and keep open_report=False.

Profile a CSV, Parquet or Excel file

import elessar

report = elessar.see("data.csv", open_report=False)
report = elessar.see("sales.parquet", target="revenue", open_report=False)
report = elessar.see("export.xlsx", sheet="2024", open_report=False)

Replace these file paths, sheet names and target names with ones from your dataset. See input formats and large-dataset behaviour.

Use the command line

elessar data.csv --no-target --open none
elessar sales.parquet --target revenue --open none
elessar data.csv --no-target --single-file --open none
python -m elessar --help

--single-file additionally writes report_single.html, with chart images inlined. An interactive terminal run without --target or --no-target can ask you to choose a target.

Inspect and export results

# Continue after the first example.
report.summary                 # pandas DataFrame, one row per column
report.alerts                  # severity, column, message and related fields
report.correlations["target"]  # target associations, when a target was supplied
report.preparation             # suggested preparation steps

report.to_json("elessar_example/report.json")
report.to_csv("elessar_example/summary.csv")
report.to_markdown("elessar_example/export.md")

To analyse without charts or automatic report files, pass plots=False. The result object remains available; use its export methods when needed.
