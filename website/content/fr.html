L’analyse exploratoire des données, en un appel Python.

Elessar est une bibliothèque Python open source pour automatiser l’analyse exploratoire (EDA) et le profilage de la qualité des données. Son nom sur PyPI est elessar. Elle nécessite Python 3.10 ou une version plus récente et utilise la licence MIT.

Installer Elessar

python -m pip install elessar

Créer un premier rapport

Cet exemple fabrique un petit jeu de données pour montrer l’API. Il ne constitue pas un benchmark statistique.

import pandas as pd
import elessar

df = pd.DataFrame({
    "quantite": [2, 4, 3, 7, 5, 9, 6, 8, 1, 4, 3, 6],
    "canal": ["web", "magasin", "web", "magasin"] * 3,
    "revenu": [20, 45, 31, 76, 53, 91, 64, 85, 12, 43, 32, 65],
})

rapport = elessar.see(
    df,
    target="revenu",
    out_dir="rapport_elessar",
    open_report=False,
)
print(rapport.summary)
print(rapport.alerts)

Avec les graphiques activés par défaut, ouvrez ensuite rapport_elessar/report.html. Le dossier contient aussi les graphiques et un rapport Markdown. Le site de documentation ne reçoit pas votre jeu de données : l’analyse est exécutée par le paquet Python.

Utiliser un fichier ou la ligne de commande

elessar donnees.csv --no-target --open none
elessar ventes.parquet --target revenu --open none

Remplacez les chemins et le nom de la cible par ceux de votre fichier. L’API Python accepte également un DataFrame pandas, des objets Polars, Arrow ou Dask, ainsi que des formats comme CSV, Parquet, Excel, JSON et SQLite.

Ce que le rapport rassemble

  • Les types sémantiques des colonnes, leur degré de certitude et le chemin de décision.
  • Les statistiques descriptives et les ajustements de distributions.
  • Les valeurs manquantes, les doublons, les alertes de qualité et les valeurs aberrantes.
  • Les associations avec tests de significativité et, lorsqu’une cible est fournie, son analyse et les alertes de fuite de données.
  • La sélection de variables, l’ACP, l’analyse factorielle et les séries temporelles lorsque ces analyses s’appliquent.
  • Un plan de préparation avec les raisons et le code proposé pour chaque étape.

Interpréter les résultats

Les alertes et les types inférés restent des diagnostics à examiner. Une corrélation ne démontre pas une causalité. Sur les gros fichiers, certaines analyses coûteuses utilisent un échantillon ; le rapport indique les résultats calculés sur l’ensemble des lignes et ceux issus de l’échantillonnage.

Cette documentation décrit la version {{VERSION}}. Consultez le protocole de validation statistique pour les méthodes et leurs limites.
