The Elessar Python API.

Use see() for a complete profile, or call a focused function for types, statistics, associations or data quality. Import public functions directly from elessar.

ParameterBehaviour
dataA DataFrame, supported tabular object, file path, URL, glob or folder. See inputs.
targetColumn to explain; None for no target, or "ask" for a picker.
configA StoneConfig instance controlling thresholds, sampling, type overrides and parallelism.
plotsWhen true, generate charts and automatic HTML/Markdown reports. False skips that generation.
out_dirExact output directory. By default, a dataset/target/date folder under elessar_report/.
verbosePrint the terminal report when true.
open_reportFalse disables automatic browser opening. None opens automatically only for a terminal run; "html" or "md" explicitly selects a report.
nameReport name. Otherwise inferred from the source or DataFrame variable where possible.
**load_optionsOptions passed to load(), such as sheet, table, sep, encoding, columns, nrows and engine.

Focused functions

The see_* functions below take a pandas DataFrame or Series, except see_column(), which requires a Series. see() and load() accept the wider set of input formats.

FunctionResult and purpose
load(source, config=None, **options)A Source object: .df, .full when applicable, and .origin. Loading only.
see_column(series, config=None, fit=True)Dictionary with semantic type, statistics, fitted distribution where applicable, alerts and errors.
see_types(df, config=None)DataFrame of semantic types, confidence, certainty, decision paths and suggestions.
see_stats(df, config=None)Descriptive statistics as a DataFrame, one row per column.
see_dist(df, config=None)DataFrame with normality tests and top distribution fits for numeric columns.
see_corr(df, target=None, config=None)Dictionary of association matrices, significance results and target analysis.
see_quality(df, config=None)Dictionary of quality checks, including alerts.
see_plot(df, out_dir, target=None, config=None)List of paths to the generated charts.
parse_dates(values, fmt=None, name=None)Pandas Series of parsed dates. Supports format inference.
suggest_targets(df, n_rows=50_000)List of ranked target candidates with metadata; does not silently choose one.
pick_target(df, how="auto")A column label selected interactively.

These are common call forms, with internal or uncommon parameters omitted. The versioned source is authoritative for complete signatures.

Configure with StoneConfig

import elessar

config = elessar.StoneConfig(
    n_jobs=1,
    random_state=42,
    column_types={"region": "categorical"},
    single_file_report=True,
)
report = elessar.see("data.csv", config=config, open_report=False)

The example assumes region is a column in your file. Type overrides are useful for category codes that look numeric. n_jobs=1 disables process parallelism; single_file_report=True additionally inlines the charts in report_single.html.

Sampling defaults in {{VERSION}}: max_rows=1_000_000, sample_size=100_000 for expensive steps and fit_sample_size=20_000 for distribution fitting. See the large-dataset guide before interpreting results.

Export with report.to_json(path), report.to_csv(path), report.to_markdown(path) and report.to_html(path). CSV exports the per-column summary. HTML exports reference chart files beside the report; use single_file_report=True during analysis for an additional report with inlined charts.
