01 / The library

Automated EDA.
Inspectable decisions.

Elessar is an open-source Python library for automated exploratory data analysis (EDA) and data-quality profiling. One call brings together column typing, descriptive statistics, distribution fitting, associations and a preparation plan.

01

Understand columns

Detect semantic types beyond pandas dtypes: identifiers, categories, numbers stored as text, dates, emails and more. Inspect the decision path and its certainty.

02

Find quality issues

Inspect missing values, duplicates, placeholders, inconsistent labels and outliers. Read alerts and suggested preparation steps before changing the data.

03

Explore relationships

Get associations with significance tests, target analysis and leakage flags. Explore feature selection, PCA, factor analysis and time-series diagnostics when applicable.

02 / Start with your data

A function.
A file.
A useful next step.

Use a pandas DataFrame in a notebook or pass a file from your terminal. The Vision result keeps the findings available as Python objects.

Reports are generated by the Python package. This documentation website does not receive or analyse your datasets.

From Python

import elessar

report = elessar.see(
    "sales.parquet",
    target="revenue",
    open_report=False,
)
report.summary
report.correlations["target"]

From the command line

elessar data.csv --no-target --open none

The revenue column must exist in your input. Without a target, use elessar.see("sales.parquet").

04 / Statistical context

A report starts an investigation.

Type inference, leakage flags and outlier decisions are diagnostics to review. Associations do not establish causation. For large datasets, some expensive analyses use samples; the report distinguishes those from full-data counts.
